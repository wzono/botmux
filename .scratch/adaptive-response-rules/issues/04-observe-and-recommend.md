# 04: 完成三天观察并给出处置建议

**What to build:** 在全量启用后的三个自然日内收集真实对话证据，区分严重正确性或安全问题、一般表达问题和偏好建议，并向用户提交保留、修改或回滚的可执行建议。

**Blocked by:** 03: 全量发布并逐机器人验收.

**Status:** ready-for-agent

- [ ] 观察窗口从全量生效并完成首轮运行验证后开始，持续三个自然日。
- [ ] 样本覆盖不同岗位、CLI、问答、执行进度、最终结果、错误和简单确认。
- [ ] 每个问题记录可复现输入、机器人、会话类型、实际输出、预期规则和严重度。
- [ ] 观察报告给出保留、修改或回滚建议，并说明证据与影响面。
- [ ] 严重问题立即举手并保存状态，但在用户确认前不执行回滚。
- [ ] 任何修改或回滚都保留发布后的并发变更，并按运行配置逐项回读验证。
