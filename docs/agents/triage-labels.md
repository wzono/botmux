# Triage Labels

The engineering skills use five canonical triage roles. Local issue files record the corresponding string in their `Status:` field.

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and agent-ready |
| `ready-for-human` | `ready-for-human` | Human implementation required |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a triage role, use the matching local status exactly.
