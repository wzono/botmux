# Domain Docs

Use the single-context domain documentation layout for this repository.

## Before exploring

- Read root `GLOSSARY.md` when it exists.
- If root `GLOSSARY-MAP.md` exists later, follow it to each glossary relevant to the task.
- Read ADRs under `docs/adr/` that affect the area being changed.
- If these sources do not exist, continue silently.

## Vocabulary

Use terms defined by the glossary in issue titles, specs, tests, and implementation notes. Do not substitute synonyms that the glossary rejects. If a needed concept is absent, reconsider whether the term is necessary or record the gap for domain modeling.

## ADR conflicts

Surface any conflict with an existing ADR explicitly. Do not silently override an accepted decision.
